Dans ce tutoriel, vous dessinez un message sur la carte de renseignements et vous voyez comment la carte évolue avec le temps. Vous travaillez avec l'exemple «Unwetter Bergdorf – Murgang Dorfbach» du tutoriel [Votre premier triage]({{< relref "/docs/user/tutorials/triage/erste-triage" >}}). Tous les noms et tous les chiffres sont fictifs.

Il vous faut :

- un événement avec au moins un message trié, attribué au domaine **Carte de renseignements**. Le résultat du tutoriel sur le triage suffit.
- environ 10 minutes.

## 1. Ouvrir la carte de renseignements

1. Dans le menu **Suivi dessiné**, ouvrez l'entrée **Carte de renseignements**.
2. La liste de gauche contient les messages qui restent à dessiner. sitrep choisit le plus ancien. Dans l'exemple, c'est le message annonçant que le groupe sanitaire 2 est arrivé.

En haut, vous voyez pour quel message vous dessinez, par exemple «&nbsp;Dessin pour le message 13 · 09:05&nbsp;».

![La carte de renseignements avec le message «Sanitätsgruppe 2 ist eingetroffen» et le bouton Terminer](/images/docs/fr/lagebild/nachrichtenkarte-arbeitsplatz.webp)

## 2. Dessiner le message

1. Cherchez la Dorfstrasse sur la carte.
2. Avec les outils de dessin de la carte, placez un objet à l'endroit indiqué, par exemple un signe pour l'emplacement du groupe sanitaire.
3. Enregistrez l'objet avec **Enregistrer**. L'objet n'est créé qu'à ce moment-là.

L'objet est lié au message et vaut dès l'heure du message.

## 3. Terminer le message

1. Cliquez sur **Terminer**.
2. Le message porte maintenant la marque «&nbsp;Dessiné&nbsp;». S'il n'y a plus d'autre message ouvert, vous lisez «&nbsp;Tous les messages sont dessinés&nbsp;».

## 4. Consulter la carte dans le temps

1. Ouvrez **Suivi dessiné**. Le calque Carte de renseignements y est en lecture seule. Vous y voyez ce que vous venez de dessiner.
2. La carte est sur **En direct**. Déplacez le moment sur la frise chronologique ou cliquez sur **Message précédent**.
3. L'objet disparaît lorsque le moment précède le message et réapparaît avec le message.

![Le tableau de la situation avec la carte et la frise chronologique en bas : curseur, boutons pour le message précédent et suivant et la marque En direct](/images/docs/fr/lagebild/lagebild-zeitstrahl.webp)

![Le même tableau de la situation à un moment antérieur : moins d'objets, la frise chronologique indique «&nbsp;État à&nbsp;» avec l'heure](/images/docs/fr/lagebild/lagebild-zeitstrahl-frueher.webp)

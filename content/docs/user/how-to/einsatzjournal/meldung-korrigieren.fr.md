Si vous avez fait une faute de frappe lors de la saisie, corrigez le message dans l'éditeur.

## Modifier un message

1. Ouvrez **Éditeur** dans le journal d'intervention.
2. Dans la liste sous le formulaire, cliquez sur **Éditer** à la hauteur du message. Vos indications apparaissent dans le formulaire.

![La liste sous l'éditeur: les messages pas encore triés ont le lien Éditer, les messages triés le lien Feuille de message](/images/docs/fr/einsatzjournal/editor-liste.webp)
3. Modifiez ce qui n'est pas correct.
4. Cliquez sur **Enregistrer**.

![L'éditeur avec un message chargé pour modification](/images/docs/fr/einsatzjournal/editor-bearbeiten.webp)

Si vous quittez la page avec des modifications non enregistrées, sitrep demande: «Vous avez des modifications non enregistrées. Ignorer et quitter?» Avec **Ignorer les modifications**, elles sont perdues.

## Corriger pendant le triage

Tant qu'un message n'est pas trié, vous pouvez aussi le corriger à la première étape du triage (**Vérifier le message**). Voir [Trier un message]({{< relref "/docs/user/how-to/triage/meldung-triagieren" >}}).

## Après le triage

Un message trié n'affiche plus que **Feuille de message** à la place de **Éditer**: l'éditeur ne le propose plus à la modification. Pourquoi le message est considéré comme figé après le triage, voir [Journal, triage et carte]({{< relref "/docs/user/explanation/einsatzjournal/journal-und-karte" >}}).

Si vous remarquez une erreur après le triage, saisissez un nouveau message qui rectifie les faits. L'entrée d'origine est conservée dans l'historique.

## Dans un événement fermé

Si l'événement est fermé, plus aucun message ne peut être modifié: «Cet événement est fermé. Les modifications ne sont actuellement pas possibles.»

La feuille de message est l'impression d'un seul message avec toutes ses indications.

## Depuis l'éditeur

1. Ouvrez **Éditeur** dans le journal d'intervention.
2. Dans la liste sous le formulaire, cliquez sur **Feuille de message** à la hauteur du message trié. Pour les messages pas encore triés, c'est **Éditer** qui s'affiche: imprimez-les depuis le triage.

![La liste sous l'éditeur avec le lien Feuille de message pour un message trié](/images/docs/fr/einsatzjournal/editor-liste.webp)
3. Dans la boîte de dialogue d'impression de votre navigateur, choisissez l'imprimante ou **Enregistrer en PDF**.

## Depuis le triage

Le triage propose **Feuille de message** dans le pied de page de chaque étape. La feuille montre alors déjà l'état actuel du flux du message et de la priorité, même si le triage n'est pas encore terminé.

## Contenu de la feuille

Les champs de la feuille de message figurent dans la référence [Champs de l'éditeur]({{< relref "/docs/user/reference/einsatzjournal/editor-felder" >}}).

Le tableau des moyens affiche l'état actuel de tous les moyens et peut être imprimé directement.

1. Ouvrez **Moyens** dans la navigation de l'événement.
2. Cliquez sur **Pour appuyer**.
3. Dans la boîte de dialogue d'impression de votre navigateur, choisissez l'imprimante ou **Enregistrer au format PDF**.

L'impression porte le titre « Tableau des moyens » avec le nom de l'événement et l'**État** avec la date et l'heure de l'impression.

![La vue d'ensemble des moyens avec le bouton Pour appuyer en haut à droite](/images/docs/fr/triage/mitteltabelle.webp)

## Ce que contient l'impression

Une ligne par moyen, triée par ordre alphabétique du nom, avec le partenaire, le nom, le nombre de personnes, le statut, les quatre heures, la tâche principale et le lieu d'engagement. Les engagements précédents d'un moyen suivent sous forme de lignes supplémentaires. Les colonnes figurent dans la référence [Vue d'ensemble des moyens et tableau des moyens]({{< relref "/docs/user/reference/triage/mitteltabelle" >}}).

{{< note type="info" >}}
L'impression montre l'état au moment où vous imprimez. Les messages qui ne sont pas encore triés n'y figurent pas. Triez-les d'abord si le tableau doit être complet.
{{< /note >}}

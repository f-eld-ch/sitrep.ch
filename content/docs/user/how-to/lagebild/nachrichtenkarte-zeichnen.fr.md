La carte de renseignements vous montre les messages qui ont été attribués au domaine **Carte de renseignements** lors du triage. Vous y dessinez ce qu'ils disent. Le tutoriel [Votre première carte de renseignements]({{< relref "/docs/user/tutorials/lagebild/erste-nachrichtenkarte" >}}) propose une introduction guidée.

## Dessiner un message

1. Dans le menu **Suivi dessiné**, ouvrez l'entrée **Carte de renseignements**.
2. Choisissez un message dans la liste. Au début, sitrep choisit le plus ancien message qui n'est pas encore dessiné.
3. Dessinez sur la carte ce que dit le message : placer de nouveaux objets, modifier ou supprimer des objets existants.
4. Cliquez sur **Terminer**.

En haut, vous voyez pour quel message vous dessinez, par exemple «&nbsp;Dessin pour le message 12 · 09:15&nbsp;». Tout ce que vous dessinez est lié à ce message et vaut dès l'**heure du message**. La raison est expliquée dans [Carte de renseignements et temps]({{< relref "/docs/user/explanation/lagebild/nachrichtenkarte-und-zeit" >}}).

![Le poste de travail de la carte de renseignements : à gauche la liste des messages, à droite le message choisi avec le bouton Terminer et la carte](/images/docs/fr/lagebild/nachrichtenkarte-arbeitsplatz.webp)

Après **Terminer**, le message indique «&nbsp;Dessiné&nbsp;» et sitrep passe au message suivant qui reste à dessiner. Lorsque tous sont dessinés, vous lisez «&nbsp;Tous les messages sont dessinés&nbsp;».

## Dessin en cours

Les nouveaux objets ne sont créés qu'avec **Enregistrer**. Si vous quittez le message avant de l'avoir terminé, sitrep demande confirmation : «&nbsp;Le dessin de ce message n'est pas terminé. Les objets déjà dessinés restent enregistrés. Quitter quand même ?&nbsp;» Avec **Quitter**, vous changez de message ; avec la croix, vous restez.

## Filtrer la liste

- Par défaut, la liste ne montre que les messages qui restent à dessiner.
- Avec **Tout afficher**, vous voyez tous les messages destinés à la carte de renseignements. Avec **Afficher les non dessinés**, vous revenez à la vue par défaut. Le nombre entre parenthèses est le nombre de messages ouverts.

## Lorsque la liste est vide

Si vous lisez «&nbsp;Pas encore de messages pour la carte des messages&nbsp;», aucun message n'a encore été attribué au domaine Carte de renseignements. Attribuez-les lors du [triage]({{< relref "/docs/user/how-to/triage/meldung-triagieren" >}}), à l'étape **Flux des messages**.

Pour modifier un message déjà dessiné : [Modifier un message dessiné]({{< relref "/docs/user/how-to/lagebild/gezeichnete-meldung-aendern" >}}).

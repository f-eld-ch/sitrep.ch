Vous modifiez les données d'un événement dans le formulaire **Modifier un événement**. Cela n'est possible que tant que l'événement est **ouvert**, et avec le rôle **Éditeur** ou supérieur.

## Ouvrir le formulaire

Vous accédez au formulaire à deux endroits.

**Dans le menu de l'événement.** Il figure sur chaque page de l'événement:

1. Ouvrez l'événement, par exemple avec **Entrer** dans la liste des événements.
2. Dans la barre de navigation en haut, passez la souris sur le **nom de l'événement**. C'est la première entrée après le logo.
3. Dans le menu déroulant, cliquez sur **Modifier un événement**. Le menu contient aussi le **Dashboard**.

![Le menu de l'événement dans la barre de navigation avec les entrées Dashboard et Modifier un événement](/images/docs/fr/ereignis/ereignis-menue.webp)

**Dans la liste des événements.** Sur la carte de l'événement, cliquez sur **Éditer**.

## Modifier le nom ou l'emplacement

1. Ouvrez le formulaire (voir ci-dessus).
2. Modifiez le **Nom de l'événement** ou l'**Emplacement**.
3. Cliquez sur **Enregistrer**.

![Le formulaire Modifier un événement avec l'emplacement modifié](/images/docs/fr/ereignis/ereignis-bearbeiten-formular.webp)

sitrep ouvre ensuite l'**Éditeur** du journal d'intervention. Le nouveau nom apparaît aussitôt dans le menu en haut.

## Modifier les domaines

- **Renommer:** modifiez le nom ou l'abréviation d'un domaine dans le formulaire.
- **Ajouter:** sous **Ajouter un nouveau domaine**, saisissez le nom et l'abréviation, puis cliquez sur le plus.
- **Supprimer:** un domaine déjà enregistré ne peut pas être supprimé. Seul un domaine nouvellement ajouté peut être retiré avant l'enregistrement, avec le bouton rouge.

Le domaine **Carte de renseignements** appartient au système. Il ne figure pas dans le formulaire et ne peut pas être modifié.

Les messages attribués à un domaine conservent leur attribution même après le changement de nom.

## Modifier l'événement parent

Dans le champ **Événement parent**, choisissez un autre événement ou « aucun événement parent ». Les conditions figurent dans [Lier un événement parent]({{< relref "/docs/user/how-to/ereignis/uebergeordnetes-ereignis-verknuepfen" >}}).

## Modifier l'accès

Sous le formulaire se trouvent le **Mode d'accès** et l'**Accès à l'événement**. La façon de les régler est décrite dans [Gérer l'accès à un événement]({{< relref "/docs/user/how-to/allgemein/ereigniszugriff-verwalten" >}}).

## Si l'événement est fermé

Un événement fermé n'a pas de bouton **Éditer**. Rouvrez-le d'abord: [Clôturer et rouvrir un événement]({{< relref "/docs/user/how-to/ereignis/ereignis-abschliessen-und-wieder-oeffnen" >}}).
